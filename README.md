# Elite Football Academy

### Developing Future Champions

Elite Football Academy is a football academy management application
designed to simplify and improve the management of football academy
operations through a modern and user-friendly interface.

## Project Information

- **Project Name:** Elite Football Academy
- **Developer & Copyright Owner:** Ahmed Kamal Ahmed Mahmoud
- **GitHub:** [AboKamal219](https://github.com/AboKamal219)
- **Framework:** Flutter
- **Language:** Dart

## Features

- Player Management
- Coach Management
- QR Code Attendance
- Training Management
- Player Statistics
- Performance Tracking
- Dashboard
- Application Settings

## Technologies

- Flutter
- Dart
- Supabase
