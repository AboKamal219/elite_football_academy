# 🚀 تشغيل المشروع من الصفر — خطوة بخطوة

المتطلبات: حساب [Supabase](https://supabase.com)، حساب Gmail (مع تفعيل التحقق بخطوتين)، Flutter ≥ 3.27 (Dart ≥ 3.0)، Android Studio أو VS Code.

## 1) مشروع Supabase
1. **New project** (اختار منطقة قريبة) واحفظ كلمة سر قاعدة البيانات.
2. من **Project Settings → API** انسخ:
   * `Project URL` → هو `SUPABASE_URL`
   * `anon public` key → هو `SUPABASE_ANON_KEY` (مفتاح عام بطبيعته، الأمان في RLS).
   * ⛔ **ممنوع** تحط `service_role` key في التطبيق أبداً.

## 2) قاعدة البيانات
1. **SQL Editor → New query** → الصق محتوى `database/FULL_SETUP.sql` → **Run**.
   * ⚠️ بيمسح كل جداول/دوال/سياسات التطبيق القديمة (مش حسابات Auth). استخدمه على مشروع مخصص للتطبيق، ومن الأفضل تجربه الأول على مشروع جديد.
   * لو ظهر خطأ: انسخ رسالته بالكامل (فيها رقم السطر) — الملفات بتتنفذ بالترتيب 00 ← 01 ← 02.
2. (اختياري للتجربة) نفّذ `database/03_seed_demo.sql` ← أكواد: `ACAD-DEMO0001` (أدمن) · `COACH-DEMO0001` · `PLAYER-DEMO0001`.
3. تأكد: `select tablename from pg_tables where schemaname='public';` لازم يطلع 14 جدول، و`select count(*) from pg_policies where schemaname='public';` أكبر من صفر.
4. **Storage:** لازم يبقى فيه bucket عام اسمه `avatars` (السكربت بيعمله؛ لو طلعت رسالة notice إنه اتخطّى → أنشئه من Dashboard > Storage).

## 3) إيميل حقيقي (Gmail) — أهم خطوة للتحقق
### أ) App Password من Google
1. حساب Google ← Security ← فعّل **2-Step Verification**.
2. افتح https://myaccount.google.com/apppasswords ← اعمل App password باسم `Supabase` ← انسخ الـ 16 حرف (بدون مسافات).
### ب) SMTP في Supabase
**Authentication → Emails → SMTP Settings** (أو Project Settings → Authentication) ← **Enable custom SMTP**:
| الحقل | القيمة |
|-------|--------|
| Sender email | حساب Gmail بتاعك |
| Sender name | `Elite Academy` |
| Host | `smtp.gmail.com` |
| Port | `465` (أو `587`) |
| Username | حساب Gmail كامل |
| Password | الـ App Password |

> سبب لازم SMTP مخصص: خدمة الإيميل الافتراضية في Supabase للتجربة فقط (حد إرسال صغير جداً، وفي المشاريع الجديدة ممكن ترسل لعناوين فريقك فقط — راجع توثيق Supabase الحالي). Gmail العادي حدّه اليومي حوالي 500 رسالة؛ للإنتاج الكبير استخدم Resend/Brevo/SendGrid بنفس الطريقة.

### ج) إعدادات التحقق
* **Authentication → Providers → Email**: فعّل **Confirm email** (ده اللي بيشغّل شاشة الكود). تأكد إن طول الـ OTP = 6.
* **Authentication → Rate Limits**: ارفع "emails sent per hour" بعد ما تفعّل SMTP المخصص.
### د) قوالب الرسائل (إجباري عشان الكود يظهر)
**Authentication → Emails → Templates**
1. **Confirm signup** ← الصق `docs/email_templates/confirm_signup.html`
2. **Reset password** ← الصق `docs/email_templates/reset_password.html`

القالب لازم يحتوي `{{ .Token }}` — ده الكود المكوّن من 6 أرقام.
### هـ) اختبار
سجّل حساب جديد بإيميل Gmail حقيقي ← لازم توصلك رسالة بالكود (راجع Spam) ← اكتبه في التطبيق.

## 4) إعداد Flutter
```bash
# من فولدر المشروع (اللي فيه pubspec.yaml)
flutter --version                 # لازم Flutter ≥ 3.27
flutter pub get
flutter analyze                   # راجع أي تحذير/خطأ قبل التشغيل
```
مفاتيح Supabase: موجودة كقيم افتراضية في `lib/services/supabase_service.dart`. **استبدلها بمشروعك** بأحد الطريقتين:
```bash
# (أ) من غير تعديل الكود — الأفضل
flutter run \
  --dart-define=SUPABASE_URL=https://xxxx.supabase.co \
  --dart-define=SUPABASE_ANON_KEY=eyJ...

# (ب) غيّر defaultValue داخل supabase_service.dart
```
الخطوط: `assets/fonts/Cairo-*.ttf` موجودة في المشروع (مُعرّفة في `pubspec.yaml`).

## 5) التشغيل
```bash
flutter devices
flutter run -d <device-id> --dart-define=SUPABASE_URL=... --dart-define=SUPABASE_ANON_KEY=...
# بناء إصدار
flutter build apk --release --dart-define=SUPABASE_URL=... --dart-define=SUPABASE_ANON_KEY=...
```
تم تعديل ملفات المنصّات: أضفنا `INTERNET` في `AndroidManifest.xml` الرئيسي (كان موجود في debug فقط، فكان الـ release APK هيفتح من غير إنترنت) و`NSPhotoLibraryUsageDescription` في `Info.plist` (اختيار صورة من المعرض كان هيعمل Crash على iOS).

## 6) سيناريو اختبار كامل (15 دقيقة)
1. **إنشاء أكاديمية جديدة** (Gmail 1) ← كود الإيميل ← داشبورد أدمن. افتح **المزيد/البروفايل** وانسخ كود المدربين/اللاعبين.
2. **مدرب** (Gmail 2) بكود المدربين. **لاعب** (Gmail 3) بكود اللاعبين. تأكد إن اللاعب مبيشوفش أكواد.
3. من حساب الأدمن: أضف فريق ← لاعب ← **تدريب** ← **من شاشة البطولات: أضف مباراة وعدّلها واحذفها**.
4. **نسيت كلمة المرور** على حساب 3 ← كود ← باسورد جديد ← دخول.
5. **الإعدادات ← اللغة ← English**: كل النصوص بتتبدل والاتجاه بيتقلب فوراً، وبترجع عربي بنفس الطريقة.
6. **حذف الحساب** من الإعدادات (حساب اللاعب).
7. اختبار الأمان: حاول من حساب لاعب تعمل `insert` على `teams` من REST — لازم يرفض (RLS).

## 7) أوامر مفيدة
```bash
flutter clean && flutter pub get      # لو حصل سلوك غريب بعد تغيير الـ dependencies
flutter analyze                       # فحص ثابت
cd tools && python3 gen_dict.py       # إعادة توليد قاموس الترجمة بعد تعديل tools/extra_en.txt
```
مراجع الأخطاء الشائعة: القسم 8 في `docs/الكتالوج_والتوثيق.md`.
